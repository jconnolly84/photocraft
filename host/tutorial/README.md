# PhotoCraft Studio: FLUX

An original GCSE trainer-advert workshop served at `tutorial/`, opened from the
PhotoCraft Home card or the host toolbar without replacing the editor.

The fifteen chapters include document size and resolution, rulers and guides,
placement, movement, layers, clipboard images, local background removal, type,
hierarchy, blend modes, layer styles, history, export and evaluation.

Thirteen silent H.264 MP4s were recorded from actual PhotoCraft interactions.
They demonstrate individual actions rather than the complete written procedure.
The background-removal clip omits the processing wait, explicitly labelled in
the video and lesson. See `assets/recording-provenance.json`.

The trainer is original AI-generated practice imagery; graphic practice assets
are generated by `scripts/create_tutorial_graphics.py`. Source and licence notes
are in the download pack. Fonts retain their OFL notices. The final advert PNG
is a 306 × 434 screen preview, not a print-resolution export. An editable
project is not shipped: the recording browser reported exporting, but its
download could not be retrieved. The optional project link stays absent.

Progress uses localStorage only. Clipboard images are written only after a user
click, with a download/Place Embedded fallback. There is no backend or student
work upload. App links open separately; closing the embedded guide pauses media.

Run `node scripts/test_tutorial_site.cjs --probe` to validate media, content and
local references. Raw recordings stay outside the repository. Encode them with
`python scripts/encode_tutorial_clips.py <capture-directory>` and ffmpeg.
